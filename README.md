# Portfolio

Personal site of K S Phanindra, full-stack developer: projects (Stride, MediVault, RoadSense), skills, experience and contact.

Built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4 and Framer Motion. Fonts: Geist and Inter via `next/font`.

## Running locally

```bash
npm install
npm run dev
```

Project screenshots in `public/shots/` are taken from the live demos at [stride-ks.vercel.app/demo](https://stride-ks.vercel.app/demo) and [medivault-ks.vercel.app/demo](https://medivault-ks.vercel.app/demo).
